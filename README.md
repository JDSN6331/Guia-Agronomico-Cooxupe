# Agronegócio Knowledge Hub

Leia a planilha que está nessa pasta e me diga o que você entende dela.

O objeitvo é criar uma aplicação descktop/mobile, usando TypeScript, HTML, CSS que sirva como uma base de conhecimento para o usuário que acessar (principalmente o time de Desenvolvimento Técnico).

Teremos um sistema de Login com validação de usuário por e-mail (administrador cria o usuário x usuário acessa o e-mail para confirmar e criar a senha).

Branchcolor relacionado ao Agronegócio.

Tema claro e escuro.

Consulte aplicações/programas semelhantes que o mercado já possui para tirar uma ideia.

Faça algo profissional, elegante, robusto e de fácil uso.

Os ícones devem ser tirados da biblioteca do site: https://www.flaticon.com/br/

Por hora vamos trabalhar com essas informações e depois vamos ajustando.
